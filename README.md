# Kushal Khatri — 3D Cybersecurity Portfolio

A cinematic Next.js + React Three Fiber portfolio for Kushal Khatri.

## Included
- Interactive 3D cybersecurity core with orbiting rings, stars, particles and network nodes.
- Glassmorphism identity card with Kushal's formal portrait.
- Dedicated 3D identity/profile section using the second portrait.
- Scroll reveal animations and elevated 3D cards.
- Responsive mobile layout.
- Contact email and LinkedIn links.
- Existing CV at `/resume.pdf`.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

The two portfolio images are stored in `public/` as `kushal-formal.jpg` and `kushal-mountain.jpg`.
